# Civics Local - System Admin Dashboard

This project is a Streamlit-based school administration dashboard with role-based access for admin and principal users.

## Prerequisites

- Python 3.10+
- A virtual environment (recommended)
- Google service account credentials file at `system_admin/Service.json`

## Setup

1. Open a terminal in the project root:
   - `d:\Civics_Local`
2. (Optional) Activate your virtual environment.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the Project

From the `system_admin` folder, run:

```bash
streamlit run universal_dashboard.py
```

You can do this with:

```bash
cd system_admin
streamlit run universal_dashboard.py
```
